# Portfolio — Tomás Lonati

Personal portfolio of a Full-Stack developer based in Buenos Aires, Argentina. Bilingual (Spanish / English), responsive, with animated sections for experience, projects, skills, education and contact.

**Live:** https://tomaslonati.vercel.app

## Stack

React 19 · TypeScript · Vite · Tailwind CSS · Framer Motion · React Router · i18next (ES/EN) · deployed on Vercel.

## Run locally

```bash
npm install
npm run dev      # dev server
npm run build    # type-check + production build
npm run lint
npm run preview  # preview the production build
```
